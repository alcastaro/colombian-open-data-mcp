# Code of Conduct

## Our pledge

This project exists to make Colombian public data reachable. Anyone with an interest
in that — a civil servant, a journalist, a researcher, a student, a developer who has
never contributed to open source before — is welcome here, regardless of background,
identity or experience.

## Expected behaviour

- **Write for the next reader.** Issues, pull requests and code comments should explain
  what and why, not only what. Someone will read them a year from now with no context.
- **Assume good faith and ask before concluding.** Most disagreements here are about
  facts — what a portal actually returns, what a licence actually permits — and those
  are settled by measuring, not by arguing.
- **Be precise about uncertainty.** "I measured this" and "I believe this" are
  different claims. Say which one you are making.
- **Spanish and English are both first-class.** Contribute in either. Public-facing
  documentation ships in both.

## Unacceptable behaviour

- Harassment, insults, or personal attacks, public or private.
- Discriminatory language or imagery, and unwelcome attention of any kind.
- Publishing someone's private information without explicit permission.
- Deliberately submitting data or code that misrepresents what a public institution
  publishes.

## Data-specific expectations

This project touches public data about real people. Two rules follow from that and
are not negotiable:

- **Never paste personal data into an issue, a pull request or a test fixture.** If
  reproducing a bug requires a specific record, describe how to find it rather than
  copying it.
- **Do not propose features that would store or redistribute datasets containing
  identifiable people.** The server reads and discards on purpose: retaining these
  datasets would make its operator a *responsable del tratamiento* under Colombia's
  Ley 1581 de 2012. That is a deliberate design limit, not an oversight.

## Reporting

Report unacceptable behaviour to **ai@olds2030.org**. Reports are handled
confidentially, and the reporter is told what happened.

Maintainers may edit, remove or reject contributions that violate this code, and may
temporarily or permanently ban any contributor for behaviour they judge harmful.
